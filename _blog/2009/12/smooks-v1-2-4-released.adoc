We’ve just made a Smooks v1.2.4 patch release (http://www.smooks.org/mediawiki/index.php?title=Downloads[Download]).

This contains:

1. Some performance enhancements (reader pooling),
2. Some bug fixes and,
3. One small new feature to support http://www.smooks.org/mediawiki/index.php?title=V1.2:Smooks_v1.2_User_Guide#Basic_Splitting_and_Routing[Basic Fragment Splitting and Routing].
